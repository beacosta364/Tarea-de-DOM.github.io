# 📅 Organizador Semanal de Tareas

Aplicación web para organizar tareas personales, laborales y académicas mediante listas personalizadas y una planificación semanal.

El proyecto permite administrar diferentes categorías de actividades, distribuir las tareas por día de la semana y realizar seguimiento de su cumplimiento desde una interfaz sencilla y adaptable a dispositivos móviles.

## ✨ Características

- **Listas personalizadas:** crear, renombrar y eliminar listas independientes.
- **Organización semanal:** distribuir las tareas entre lunes y domingo.
- **Gestión de tareas:** agregar, editar y eliminar tareas.
- **Seguimiento de actividades:** marcar las tareas como completadas o pendientes.
- **Reinicio semanal:** restablecer el estado de las tareas al comenzar una nueva semana, conservando su contenido y organización.
- **Persistencia local:** guardar la información en el navegador mediante `localStorage`.
- **Diseño adaptable:** interfaz responsive para computadores, tabletas y celulares.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido de la aplicación.
- **CSS3:** estilos, diseño visual y adaptación a dispositivos móviles.
- **JavaScript:** lógica de la aplicación, interacción y administración de tareas.
- **LocalStorage:** almacenamiento de los datos en el navegador.

## 🚀 Cómo utilizar la aplicación

1. Accede a la aplicación desde el navegador.
2. Crea una lista con el nombre que prefieras, por ejemplo: Personal, Trabajo o Universidad.
3. Ingresa a la lista que deseas organizar.
4. Selecciona el día de la semana correspondiente.
5. Añade las tareas que necesitas realizar.
6. Marca cada tarea como completada cuando termines.
7. Edita o elimina las tareas y listas según tus necesidades.

## 💾 Almacenamiento de datos

La aplicación utiliza `localStorage` para conservar las listas y tareas en el navegador.

Los datos permanecen guardados después de cerrar o recargar la página, siempre que no se borre el almacenamiento del navegador.

**Nota:** la información no se sincroniza automáticamente entre diferentes dispositivos o navegadores.

## 🎨 Diseño

La interfaz utiliza una paleta de colores basada en azul marino, cian, gris y blanco, con tarjetas, botones y elementos visuales diseñados para ofrecer una experiencia clara y organizada.

El diseño responsive adapta la distribución de los elementos según el tamaño de la pantalla.
